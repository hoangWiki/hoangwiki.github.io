1. Overview

This Privacy Policy explains what data the ProfileLens - LinkedIn AI Companion Chrome extension reads, how it is used, and who it is shared with. ProfileLens has no backend server operated by us — all data flows directly from your browser to the third-party APIs described below.

2. What data ProfileLens reads

When you click "Analyze Profile" on a LinkedIn profile page (linkedin.com/in/*), the extension reads the following from that page's visible content:

  • Name and headline
  • "About" section text
  • Up to 3 recent work experience entries
  • Up to 2 recent activity posts shown on the profile

This happens only on user action (clicking Analyze) — ProfileLens does not scrape or read profile data automatically or in the background.

3. How this data is used and who it is shared with

  • Anthropic (api.anthropic.com): The profile text extracted in step 2 is sent directly from your browser to Anthropic's Claude API, using your own Anthropic API key that you provide in the extension popup, to generate conversation starters, highlights, and outreach suggestions. We do not operate this API and never receive or store a copy of this data ourselves.
  • Polar.sh (api.polar.sh): If you activate a Pro license key, that key is sent to Polar.sh's API to verify it is valid and active. No profile or personal data is included in this request — only the license key string.

We do not sell, rent, or use this data for advertising. We do not operate any analytics or tracking service inside the extension.

4. What is stored, and where

  • Your Anthropic API key — stored in chrome.storage.local on your device only. Never transmitted to us.
  • Your Polar.sh license key (Pro users only) — stored in chrome.storage.local on your device only.
  • Monthly usage count (a number, e.g. "3 of 10 free analyses used") — stored in chrome.storage.sync so it follows your Chrome profile across devices. Contains no profile content.

Analyzed profile content itself (name, headline, about, experience, activity) is never stored by the extension — it is read, sent to Anthropic for that single request, and discarded from memory once the response is shown.

5. Data retention and deletion

Uninstalling ProfileLens, or clearing its storage from chrome://extensions, permanently deletes the API key, license key, and usage count from your device. Because we never receive or store this data on a server, there is nothing further for us to delete on our end.

6. Changes to this policy

If this policy changes, the updated version will be published at this same URL and reflected in the extension's Chrome Web Store listing.
